# Ruslan Savchuk — Astro

Портфоліо на Astro зі статичною збіркою. Дизайн, анімації та інтерактивні елементи перенесені з початкової HTML-версії. Сайт підтримує українську, англійську та французьку мови.

## Запуск

Потрібен Node.js 24 LTS (або сумісний Node.js від 22.23.4) та npm від 9.6.5. Якщо використовуєте nvm, виконайте `nvm use`: версію вказано в `.nvmrc`.

```sh
npm install
npm run dev
```

Відкрийте адресу, яку виведе Astro, зазвичай `http://localhost:4321`.

## Перевірка й публікація

```sh
npm run check
npm run build
npm run preview
```

`npm run build` створює готовий сайт у `dist/`. Для статичного хостингу задайте команду збірки `npm run build` і папку результату `dist`. Вміст `src/` не потрібно завантажувати як готовий сайт. Після зміни вихідних файлів повторіть збірку.

## Де редагувати

- `src/pages/index.astro` — порядок секцій головної сторінки.
- `src/layouts/SiteLayout.astro` — HTML-документ, метадані та підключення стилів і скриптів.
- `src/components/` — шапка, секції, футер і вікно опису проєкту.
- `src/components/BrandLogo.astro` — спільний логотип RS, ім’я та підпис професії в шапці й футері.
- `src/styles/styles.css` — початкові глобальні стилі, адаптивність і CSS-анімації.
- `src/styles/theme.css` — темна палітра. Порядок стилів задає `src/styles/global.css`.
- `src/data/config.js` — ім’я, назва, email і посилання на соціальні мережі.
- `src/data/projects.js` — додаткові роботи та переклади їхніх описів. Деталі — у `PROJECTS.md`.
- `src/scripts/app.js` — переклади, мови, меню, фільтри, проєкти та форма.
- `src/scripts/motion.js` — анімації появи, рух ілюстрації та індикатор прокручування.
- `public/assets/` — оригінальні зображення, шрифти та favicon; доступні за адресами `/assets/...`.

Новий бренд RS використовує сині акценти на темному тлі. Оригінальне зображення, підготовлений знак і параметри його створення описані в `BRAND.md`.

Astro збирає клієнтський код з `src/scripts/client.js`: спочатку створюються проєкти та обробники, потім підключаються анімації. Налаштування й роботи імпортуються як JavaScript-модулі.

Мова визначається з `?lang=uk`, `?lang=en` або `?lang=fr`, збереженого вибору та налаштувань браузера. Вибір користувача зберігається між відвідуваннями. Якщо серед мов браузера немає української, англійської чи французької, відкривається англійська версія.

## Контактна форма

Кнопка «Відправити» надсилає заявку через `POST /api/contact` у Cloudflare Worker. Телефон необов’язковий: поле приймає довільний формат без маски. Ім’я, email, послуга й повідомлення перевіряються також на сервері.

Листи адресовані лише `ruslan.savchuk.dev.ca@gmail.com`, відправник — `website@forms.ruslansavchuk.com`. Email клієнта встановлюється у `Reply-To`, щоб відповісти йому безпосередньо. Текст листа підтримує українські символи й довільний текст телефону. Адресат заданий у `worker/contact.ts` і обмежений binding `CONTACT_EMAIL` у `wrangler.jsonc`; відвідувач не може його змінити.

У Cloudflare мають бути увімкнені Email Routing для `forms.ruslansavchuk.com` та підтверджена адреса одержувача. Поштові записи основного домену не потрібно замінювати. `wrangler.jsonc` додає email binding, обмеження 5 спроб за 60 секунд на IP у кожному розташуванні Cloudflare та передає маршрути `/api/*` серверному обробнику. Приховане поле відсіює простих ботів. Дані клієнтів не записуються в логи.

Форма показує успіх лише після прийняття листа поштовим сервісом. Під час запиту повторне відправлення заблоковане. Якщо сталася помилка або втрачено мережу, введені дані залишаються у формі.

Локальна перевірка всього сайту разом із серверним обробником:

```sh
npm run build
npm run preview:worker
```

Wrangler виведе локальну адресу, зазвичай `http://localhost:8787`. У локальному режимі email binding імітує надсилання, реальний лист не відправляється. `npm run dev` і `npm run preview` запускають лише Astro та не містять серверного маршруту форми.

```sh
npm test
npm run check
npm run deploy:check
```

Остання команда перевіряє пакет Cloudflare без публікації. Після дозволеної публікації через GitHub автоматична команда `npx wrangler deploy` використає конфігурацію з репозиторію. Реальну доставку листа потрібно перевірити після розгортання.
