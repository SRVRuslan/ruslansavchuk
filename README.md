# Ruslan Savchuk — Astro

Портфоліо на Astro зі статичною збіркою. Дизайн, анімації та інтерактивні елементи перенесені з початкової HTML-версії. Сайт підтримує українську, англійську та французьку мови.

## Запуск

Потрібен Node.js 24 LTS (або сумісний Node.js від 22.23.4) та npm від 9.6.5. Якщо використовуєте nvm, виконайте `nvm use`: версію вказано в `.nvmrc`.

```sh
npm install
npm run dev
```

Відкрийте адресу, яку виведе Astro, зазвичай `http://localhost:4321`.

## Перевірка й публікація

```sh
npm run check
npm run build
npm run preview
```

`npm run build` створює готовий сайт у `dist/`. Для статичного хостингу задайте команду збірки `npm run build` і папку результату `dist`. Вміст `src/` не потрібно завантажувати як готовий сайт. Після зміни вихідних файлів повторіть збірку.

## Де редагувати

- `src/pages/index.astro` — порядок секцій головної сторінки.
- `src/layouts/SiteLayout.astro` — HTML-документ, метадані та підключення стилів і скриптів.
- `src/components/` — шапка, секції, футер і вікно опису проєкту.
- `src/components/BrandLogo.astro` — спільний логотип RS, ім’я та підпис професії в шапці й футері.
- `src/styles/styles.css` — початкові глобальні стилі, адаптивність і CSS-анімації.
- `src/styles/theme.css` — темна палітра. Порядок стилів задає `src/styles/global.css`.
- `src/data/config.js` — ім’я, назва, email і посилання на соціальні мережі.
- `src/data/projects.js` — додаткові роботи та переклади їхніх описів. Деталі — у `PROJECTS.md`.
- `src/scripts/app.js` — переклади, мови, меню, фільтри, проєкти та форма.
- `src/scripts/motion.js` — анімації появи, рух ілюстрації та індикатор прокручування.
- `public/assets/` — оригінальні зображення, шрифти та favicon; доступні за адресами `/assets/...`.

Новий бренд RS використовує сині акценти на темному тлі. Оригінальне зображення, підготовлений знак і параметри його створення описані в `BRAND.md`.

Astro збирає клієнтський код з `src/scripts/client.js`: спочатку створюються проєкти та обробники, потім підключаються анімації. Налаштування й роботи імпортуються як JavaScript-модулі.

Мова визначається з `?lang=uk`, `?lang=en` або `?lang=fr`, збереженого вибору та налаштувань браузера. Вибір користувача зберігається між відвідуваннями.

Контактна форма, як і раніше, завантажує текстовий бриф і готує лист у поштовій програмі. Остаточне надсилання виконує відвідувач у своїй поштовій програмі.
